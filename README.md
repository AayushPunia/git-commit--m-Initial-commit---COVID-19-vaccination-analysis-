# 🇮🇳 COVID-19 Vaccination Data Analysis (India, 2020–2023)

This project analyzes the COVID-19 vaccination rollout in India using real-world data. It covers trends in total and daily vaccinations, first vs second dose coverage, booster rollout, per-hundred population metrics, and monthly patterns.

## 📊 Project Objectives

1. **Overall vaccination progress over time**
2. **Comparison between first and second dose coverage**
3. **Vaccination rates per hundred population**
4. **Booster dose rollout and impact**
5. **Monthly trends in vaccination progress**

## 📁 Dataset

- **Format:** Excel (.xlsx)
- **Columns used:**
  - `date`
  - `total_vaccinations`
  - `daily_vaccinations`
  - `people_vaccinated`
  - `people_fully_vaccinated`
  - `total_vaccinations_per_hundred`
  - `people_vaccinated_per_hundred`
  - `people_fully_vaccinated_per_hundred`
  - `total_boosters`
  - `total_boosters_per_hundred`
